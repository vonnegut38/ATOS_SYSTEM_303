OTWARTE UWAGI DLA AUTORA PORTU
1. Dźwięk jest niezaimplementowany: plat_song i plat_sfx są pustymi funkcjami.
   README o braku PCM w ATOS jest już nieaktualne: obecny system ma PCM U8 mono
   12288 Hz przez YM2149 (ABI 1.5). Muzyka TRK wymaga jednak dekodera/miksera;
   dołączenie samych plików TRK jej nie uruchamia.
2. GAME=3 przy zegarze 70 Hz oznacza tempo 23,333 klatki/s, nie 30 lub 40.
   Nie przyspieszać samego timera bez oddzielenia symulacji od prezentacji.
   card2x w jądrze nadal kopiuje pełne zmiany 640x400; pionowe przewijanie
   i kurtyny mają większy koszt niż ruch duszków. Optymalizować po pomiarze,
   z regresją Flashbacka, nie podmieniać starego jądra z pakietu gry.
3. apply_late_breaks zeruje jednocześnie held_kbd i held_joy. Przy jednoczesnym
   sterowaniu klawiaturą i joystickiem zwolnienie krótkiego naciśnięcia jednego
   źródła może skasować przytrzymanie drugiego. Należy odraczać break osobno
   dla każdego źródła. Testy niniejsze dotyczą klawiatury, nie obu naraz.
4. Brak walidacji --level oraz część ścieżek braku pamięci/plików jedynie
   raportują GAP. Dodać kontrolę zakresu i jawne wyjście przy błędzie danych.
   Nie dowiedziono kompletnej zgodności całego silnika: pozostają gałęzie GAP.
5. Tryb to natywna aplikacja ATOS na 68030/ET4000, nie program .PRG/TOS.

STEROWANIE
Spacja: przejście OLDIES / zatwierdzanie / atak. 1: nowa gra, 2: kod.
Strzałki: ruch; góra: skok. Esc lub Alt+X: wyjście do pulpitu.
Prezentacja tytułowa ma własną sekwencję animacji — nie każda spacja ją skraca.

POTWIERDZENIE ROZGRYWKI W HATARI
Po przejściu menu MODE / BEGINNER, w rzeczywistej sesji (flaga demo 0),
sprawdzono strzałkę w prawo, w lewo, skok, atak, przewijanie i utratę energii.
Zrzuty 19–22 dokumentują różne pozycje gracza; obraz nie jest tylko demem.
Esc przywrócił pełny pulpit i paletę (zrzut 23), bez wyjątku procesora.
Ponowny start PRE2 z ikony i ponowne wyjście także poprawne (zrzut 24).

Próba dodatkowego otwarcia SysInfo po teście PRE2 jest nierozstrzygnięta:
automatyzacja zgłosiła TOS STARTED, ale zrzut nie potwierdził okna. Nie zaliczam
tego jako testu SysInfo; jego binarka oraz jądro nie były zmieniane.
