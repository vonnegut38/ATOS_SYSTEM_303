# Reference behaviour for ATOS compatibility (v10, Phase 17)

| Platform | Role |
|---|---|
| TOS 2.06 | historic reference behaviour |
| EmuTOS   | open-source implementation reference |
| ATOS     | implementation under test |

Rules:
1. Do not copy TOS bugs unless required for compatibility.
2. Document every deliberate difference from TOS 2.06 below.
3. A difference in a test result between platforms is a compatibility bug until
   explained; fix the ATOS implementation, never special-case the test program.
